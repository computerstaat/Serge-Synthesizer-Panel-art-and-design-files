# Custom panels

17" panels laid out the way real owners configured them, from photos (STS and SMMS systems). Every module on them
is in the Modern module set; only the arrangement is the owner's. SVGs are in `Vector Graphics/Full Panel/Custom`,
drill templates in `Drill Templates/Full Panel/Custom`.

| Panel | Modules, left to right |
|---|---|
| Random_Source_NTO_Two_VCFQ | Random Source, Dual Transient Generator, New Timbral Oscillator, Precision VCO, X Fader, ÷N Comp, Ring, Variable Q VCF ×2 |
| Adapters_Scaling_Quadrature | Adapters ×4 (STS), Scaling Processor ×2, Quadrature Oscillator ×4 |
| Sequencing_Programmers_4_5_4 | 4-, 5- and 4-Stage Sequencing Programmers |
| Random_Source_Extended_ADSR | Random Source, ÷N Comp, Dual Processor, Scaling Processor, Active Processor, Smooth and Stepped Function Generators, Extended ADSR ×2, Preamp Detector |
| Preamp_Precision_Stereo_Mixer | Preamp Detector, Precision VCO, Ring, ÷N Comp, Wave Multipliers, Triple Waveshaper, Variable Bandwidth VCF, Audio Mixer, X Fader, Dual Channel Stereo Mixer |
| Cabinet_Middle_Panel | Preamp Detector, Precision VCO ×2, Wave Multipliers, Audio Mixer, Variable Q VCF, DUSG, Universal Audio Processor |
| Cabinet_Bottom_Panel | 7-Stage Sequencing Programmer, Active Processor, DUSG, Variable Slope VCF, Noise Source |
| Sequencer_Quadrature_DUSG | Sequencer, Quantizer (TKB), ÷N Comp, Pulse Divider, Quadrature Oscillator, DUSG ×2 |
| DUSG_Quad_VCA_UPAP | DUSG, Adapter ×2 (SMMS), Quad VCA, DUSG, Universal Equal Power Audio Processor |
