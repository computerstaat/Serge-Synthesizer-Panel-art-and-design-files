# Documentation

| File | What it is | Era |
|---|---|---|
| `1973_Paper_Face_Modules_First_Users_Guide.pdf` | First user's guide for the 1973 paperface modules, with labelled panel drawings | Paperface |
| `SMMS_Owners_Guide_1978.pdf` | SMMS Owner's Guide (1107½ N. Western Ave, Hollywood): test patches drawn on hand-sketched panels of the squared-box modules (NTO, PCO, Quad VCA, Dual Cross-Fader, UPAP, Ring, VCFQ, Extended Range VCF, DSG, DTG, Dual Random Generator, Router, Triple Comparator, KEG, SSG, ASR) | SMMS paper, squared boxes |
| `Visual_Thinking_Electronic_Music_Theory.pdf` | "Electronic Music Theory" and "Learning Patch Number Two": sound basics and step-by-step Serge patches with block diagrams (oscillator, filter, TKB, DSG, envelopes) | teaching material |
| `SMMS_Catalogue_1979.pdf` | Serge Modular "Series 79" catalogue, with a July 1980 price list | SMMS, squared boxes |
| `SMMS_Catalogue_1980.pdf` | Serge Modular Music Systems catalogue and data sheets, with a July 1983 price list | SMMS, rounded boxes |
| `Serge_Modular_Music_Systems_STS_Catalog.pdf` | A later edition of the same catalogue (same drawings and Haight Street address) | SMMS rounded / Modern layout |
| `An_Introduction_to_the_Serge_Modular_Music_System.pdf` | Rich Gold's introduction and user's manual | SMMS |

See [Serge_History.md](Serge_History.md) for the timeline and how the panel graphics were made, and [SMMS_Catalogue_Notes.md](SMMS_Catalogue_Notes.md) for what the two SMMS catalogues tell us.
