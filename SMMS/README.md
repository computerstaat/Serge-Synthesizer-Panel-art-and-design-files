# SMMS (Serge Modular Music Systems)

The middle era of Serge panels, about 1976 to 1992: the module name on top and "serge", "SERGE MODULAR" or
"SERGE MODULAR MUSIC SYSTEMS" printed underneath. They sit between the early geometric-symbol Paperface panels
(`../Paperface`, 1973–76) and the STS panels, whose graphics are printed directly on the metal.

The change to STS came in 1992, when Serge sold the designs to Rex Probe; STS printed the graphics directly on the
metal. Before that, a metal-looking panel is usually an SMMS metal overlay.

The SMMS panels are split by how the graphics were put on the aluminium panel (see
`../Documentation/Serge_History.md`):

- **[`Paper/`](Paper/README.md), about 1976–79:** printed paper (later with a Mylar overlay) stuck on the panel.
  Function names instead of the early geometric symbols; squared boxes with the module name in the top edge. The
  style of the 1979 catalogue (`../Documentation/SMMS_Catalogue_1979.pdf`).
- **[`Metal_Overlay/`](Metal_Overlay/README.md), about 1979 to the early 1990s:** an adhesive metallic sheet with
  the graphics photo-exposed onto it, usually black lettering on silver and occasionally reversed (silver on black,
  like the Cal Arts Black Serge). Rounded boxes, name above the outline, "serge" in the bottom edge. The style of the
  1980 catalogue (`../Documentation/SMMS_Catalogue_1980.pdf`).

Nothing has been drawn for this era yet. A module is only added once a photo confirms the
SMMS version of its panel (paper or metal overlay). The rounded layouts in `../Modern` are the same drawings the
metal-overlay panels used.

Each subfolder follows the same layout as `Modern` once panels are added:

```
Paper/Images/<category>/<name>.png      Metal_Overlay/Images/<category>/<name>.png
Paper/Vector Graphics/<category>/...    Metal_Overlay/Vector Graphics/<category>/...
Paper/Drill Templates/<category>/...    Metal_Overlay/Drill Templates/<category>/...
```

Each subfolder's README lists the modules photo-confirmed in that style.
