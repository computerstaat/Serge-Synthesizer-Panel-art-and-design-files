# SMMS (Serge Modular Music Systems)

The middle era of Serge panels: **printed paper faces** (white, cream or yellow) with the module name on top
and "serge", "SERGE MODULAR" or "SERGE MODULAR MUSIC SYSTEMS" printed underneath. They sit between the 1970s
Paperface panels (`../Paperface`, also paper, in the simpler early style) and the Modern panels (`../Modern`), the
later STS panels printed directly on aluminium.

There are two versions of SMMS artwork:

- **Squared boxes** (older, about 1978–79): square-cornered boxes, the module name inside the top of the outline.
  This is the style of the 1979 catalogue (`../Documentation/SMMS_Catalogue_1979.pdf`).
- **Rounded boxes** (newer, 1980 on): rounded boxes with the name above the outline and "serge" in the bottom edge.
  This is the style of the 1980 catalogue (`../Documentation/SMMS_Catalogue_1980.pdf`) and the later STS catalogue,
  and the same layout the Modern (aluminium) panels kept.

Nothing has been drawn for this era yet. A module is only added once a photo confirms the
SMMS version of its panel (and which of the two box styles it uses).

The folder is split by artwork version: [`1979/`](1979/README.md) for squared boxes and [`1980/`](1980/README.md) for rounded boxes. Each follows the same layout as `Modern` once panels are added:

```
1979/Images/<category>/<name>.png      1980/Images/<category>/<name>.png
1979/Vector Graphics/<category>/...    1980/Vector Graphics/<category>/...
1979/Drill Templates/<category>/...    1980/Drill Templates/<category>/...
```

Each subfolder's README lists the modules photo-confirmed in that style.
