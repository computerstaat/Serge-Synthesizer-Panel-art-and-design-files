# SMMS metal overlay (about 1979 to the early 1990s): rounded boxes

The newer SMMS artwork, as drawn in the 1980 catalogue (`../../Documentation/SMMS_Catalogue_1980.pdf`): rounded
boxes, the module name above the outline and "serge" in the bottom edge. The graphics are an adhesive metallic sheet
with the artwork photo-exposed onto it, normally black on silver; some systems used positive masters for silver on
black (the Cal Arts Black Serge, `../../Systems/CalArts_Black_Serge.md`). The Modern (aluminium)
panels kept these layouts, so the drawings in `../../Modern` are the reference for these too.

Photo-confirmed in this style, not drawn yet:

|---|---|
