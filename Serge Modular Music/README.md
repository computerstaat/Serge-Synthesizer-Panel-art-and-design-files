# Serge Modular Music

The middle era of Serge panels: **printed paper faces** (white, cream or yellow) with the module name on top
and "serge", "SERGE MODULAR" or "SERGE MODULAR MUSIC SYSTEMS" printed underneath. They sit between the 1970s
hand-drawn paperface panels (`../Paperface`, also paper) and the Modern panels (`../Modern`), which are printed
directly on aluminium.

Nothing has been drawn for this era yet. A module is only added once a photo confirms the
Serge Modular Music version of its panel.

Once panels are added, the folder follows the same layout as `Modern`:

```
Images/<category>/<name>.png
Vector Graphics/<category>/<name>.svg
Drill Templates/<category>/<name>.pdf
```
