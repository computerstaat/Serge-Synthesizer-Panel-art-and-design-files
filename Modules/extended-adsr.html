How it works

GATE and TRIG start the envelope; each stage has its own voltage-control input and knob, so the envelope's shape can be modulated while it plays.

1V/OCT (or VC ALL) scales all the stages together so envelopes get shorter as notes get higher. A switch picks the envelope shape, and an LED shows activity.
