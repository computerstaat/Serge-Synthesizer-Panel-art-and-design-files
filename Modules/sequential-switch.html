How it works

Each clock pulse moves the switch to the next position, like a rotary switch turned by a pulse; it passes audio or control voltages in either direction, so it can pick one of several inputs or send one input to several outputs.

Reset returns it to the first position and the up/down control sets the direction; an inhibit input stops it stepping. With knobs on the positions and an LFO on the clock it becomes a small voltage sequencer.

The CGS panels have eight positions; the Prism and Low-Gain boards switch four, so check the stage count of the board you choose.
