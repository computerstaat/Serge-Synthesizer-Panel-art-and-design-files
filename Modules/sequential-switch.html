Sequential Switch

How it works

Each clock pulse selects the next input, like a rotary switch turned by a pulse, and passes it to the common output; audio and control voltages both pass, and each position gives its own gate while it is selected.

Reset returns to the first position, the up/down control sets the direction and inhibit holds the current position. With knobs feeding the inputs and an LFO on the clock it is an eight-step voltage sequencer.

The Prism and Low-Gain sequential switches are different circuits: bidirectional, with four positions.

The CGS328 is a multiplexer: it routes one of eight inputs to its output (not the other way round) and gives a gate for each selected input. It handles +/-10 V and can count up or down, so it matches this 8-position panel.

Ken Stone's original page (earlier board, background and how it works): https://open4umodular.github.io/synthpanel/modules/cgs28_seq_switch.html
